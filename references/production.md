# 制作工具与操作要点

本目录上一层的 `scripts/` 继承原 handout-builder 的工具。运行前确认依赖，使用环境中实际可用的 Python；文档渲染依赖优先通过 workspace dependencies 工具定位。这里描述操作约束，不是已通过本次内容验收的证明。

| 脚本 | 用途 | 使用边界 |
|---|---|---|
| `analyze_template.py` | 模板字体、字号、页面和段落分析 | 分析真实正文及 run，不能仅看样式表 |
| `pdf_extract.py` | 题目标记索引、图块定位、页面与区域裁剪 | 标记索引不覆盖所有正文，坐标归属须原页复核 |
| `glyph_ascii.py` | 疑难数字和符号高清点阵 | 提供字形证据，不能凭答案猜字符 |
| `docgen.py` | 模板作为基底生成可编辑正文与内联图片 | 显式传样式配置；公式和表格按需另用原生结构 |
| `test_pdf_extract_crop.py` | 裁图几何及图注保留回归 | 验证辅助算法，不证明真实题目已裁对 |

依赖：python-docx、PyMuPDF（fitz）、Pillow。先运行导入检查；有缺失再使用现有运行环境或隔离环境解决，不默默改变全局依赖。

## 索引与转录

`Extractor` 按文件名排序编号。将固定源 ID 对应文件链接到任务的 `src/`，如 `S01.pdf`；建立索引后不得假设编号与源 ID 一致，记录并回读 `catalog[fid]['rel']` 的实际映射。后续加文件应更新映射并核对旧单元。

工具示例（脚本路径相对本技能目录）：

```bash
python3 scripts/analyze_template.py 模板.docx 工作目录/
python3 scripts/glyph_ascii.py 素材.pdf -p 页码 -r x0,y0,x1,y1
python3 scripts/test_pdf_extract_crop.py
```

调用前查看 CLI 帮助或实现确认页码基准；来源台账始终用从 1 开始的物理页码。

有文本层也逐块对照原页；路径化下标可能没有缺字符标记。疑难区域先渲染 300–600dpi，必要时单字提高到可辨认分辨率。OCR 或已有 WPS 转换稿提供独立候选，原页是最终依据。不中立的提示、常见题型和“能算出整数答案”都不能裁决原文。

## 图块裁剪

`crop_problem_figs`、`crop_fig`、`crop_rect` 和 `crop_question_card` 的实际参数以脚本为准。默认仅收白边，保留甲乙丙、单位、刻度与 A–D 标签。`fig_only` 可能删分离图注，只有确认无图注且确实需要清理边带时才使用。

题号、邻题和图注位置是定位线索，不是图题归属证明。配图可能由路径、文字及多幅位图组成，不能以嵌入位图 bbox 或尺寸阈值决定完整图界。出现边界不确定或图注越界警告时回到带邻域的整页预览，修正裁剪框，再对照源图。

左侧题干右侧配图不等于双栏；两侧都有独立题目并结合阅读顺序才判断双栏。跨页题与共用图按单元依赖提取。表盘读数题保留指针原图，不把待求读数写入题干。

保存像素尺寸、非白像素比例和显示尺寸；它们拦截空白或低分辨率，不能证明裁对。不要按默认 5.5cm 缩窄所有图片，显式传适合细节和文本宽度的尺寸。

## Word 生成

`DocBuilder(template_path, profile)` 清除模板正文，保留模板样式与页脚。保存前检查是否残留模板页眉、旧讲次和无关信息。该工具不会自动复刻模板的直接格式：`DEFAULT_PROFILE` 仍是旧学而思配置，含空心字体和彩色栏目；直接传模板不代表使用“讲义版”。

依据模板分析结果显式提供 profile。`FormatProfile` 仅做顶层浅更新，覆盖 title/body 等嵌套字段时给出完整字段；字号 `sz` 为半磅。普通无模板回退可采用如下配置，并把文档页面明确设为 A4 与四边 2.2cm：

```json
{
  "ascii_font": "Calibri",
  "east_font": "宋体",
  "banner_font": "宋体",
  "title": {"sz": 28, "color": "000000", "line": ["300", "auto"]},
  "section": {"color": "000000"},
  "points": {"color": "000000", "label": "知识要点"},
  "banner": {"line": ["300", "auto"]},
  "body": {"sz": 21, "indent": 0}
}
```

`section()` 当前沿用正文字号，`make_p()` 默认行距也不等于 1.25 倍；需要 12pt 小标题和 1.25 倍行距时，使用显式 run/段落格式或保存前统一设置，不能声称只传 profile 就实现。已有模板则按实测格式设置。

`example(lines)`、`exercise(lines)` 将每个列表元素生成一段，不传 PDF 视觉折行作为段落。例题当前加粗、练习常规，模板要求不同时自行设置。复杂公式用 OMML 或原生上下标 run，表格用原生表格；这些不是当前简单文本方法自动支持的能力。

保存后重新打开检查内容、页面设置与 OOXML 结构，并渲染各页。实际复制粘贴另行验证；不把渲染或算法回归写成粘贴验证通过。
