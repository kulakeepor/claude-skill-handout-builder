# 选材与教学设计

## 目标写成可检查的行为

“理解电功率”太宽。可写为“能在明确额定与实际状态的条件下，选择适用关系计算实际功率，并说明判断依据”。写清表现、条件与达标证据；未知学生水平不能靠难度标签代替诊断。

每项核心目标追踪到独立检查。识记目标可以概念辨别；方法目标需要独立运用；迁移目标需要改变情境或条件。增加一道难题不自动等于迁移。

## 判断候选内容

| 维度 | 判断问题 | 取舍依据 |
|---|---|---|
| 目标相关性 | 完成目标是否需要它？ | 不相关材料通常排除 |
| 先修要求 | 学生能否开始做？ | 补最小必要先修，或调整顺序 |
| 教学作用 | 示范、辨析误区、巩固还是迁移？ | 相同用途且无新增价值时删减 |
| 新增价值 | 改变了什么认知要求？ | 不能仅按数字或题名判断重复 |
| 信息完整性 | 条件、图表、选项、续页是否齐全？ | 不完整不能作为已核验题 |
| 课堂成本 | 读题、讲解、尝试、反馈分别耗时多少？ | 用估计区间并说明依据 |
| 可访问性 | 图线、字号和表达能否看懂？ | 可用于等效材料之间的取舍 |

定性说明即可；无实测依据不制造精确难度分、成功率或“最优”排名。

## 按用途组织

- 初学：引出问题 → 必要概念或表征 → 示范 → 有支架的尝试 → 独立检查。
- 专题复习：诊断 → 补薄弱方法 → 对比易混条件 → 独立运用 → 综合迁移。
- 课后练习：必要提示 → 分层独立练习 → 按需提供独立答案；无须强加课堂讲解栏目。

这是结构选项，不是固定栏目或题数配额。例题难度、支架撤除速度和练习量由目标与学生条件决定。

## 去重边界

先比较解题路径、概念条件、图形关系与学生所需决策，再比较文字。完全相同的题留清晰可靠的一份，记录其他出处。声称“最新版”的来源仍看实际内容，不能仅按文件名决定优先级。

原题用于两次诊断或前后对照可以保留，说明用途。来源之间有数据冲突时记录各自出处，不拼接成一个未经验证的题。

## 时间与缺口

总时间包含概念解释、示范、学生尝试、讨论反馈、过渡和机动时间。估时不是事实；不用固定“每小时多少题”的通用公式。

超时先删无新增价值材料，再把拓展转为可选，最后调整覆盖范围。仍无法满足硬性要求时列出具体冲突。缺少目标材料时可重组已有材料，或在已允许的新编范围内补充；否则明确缺口，不冒充源材料。
