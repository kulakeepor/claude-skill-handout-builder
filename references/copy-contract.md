# 复制和样式协议

## 模板

用户明确模板优先；使用用户提供或当前环境已确认的讲义版参考模板，不依赖作者机器上的私人文件路径。

路径失效时搜索实际文件；不可把另一个文档默认为同一模板。分析有内容的样例段落和 run，包含中文/西文/数学字体、字号、行距、缩进、题号、表格和插图。模板中的正文格式可能为直接格式，不能只复制 styles.xml。栏目和题号按已确定的组编蓝图生成；不要继承无关源文栏目。

模板不可用时采用 A4、四边 2.2cm、宋体正文 10.5pt、标题 14pt 加粗、节标题 12pt 加粗、正文 1.25 倍行距，使用常见西文字体。题号按蓝图重编号，保留原号到输出编号的映射；示范题可用【例N】内联标签。不增加空心字体、彩色装饰或 emoji。

## 稳定的正文流

- 一段承载一个语义段落。视觉折行由 Word 计算；选项、分题、表格保留结构。禁止用空格、Tab 和超宽缩进模拟坐标。
- 图片使用 `wp:inline`，保留比例，宽度不超过可用文本宽度，有效 DPI 通常至少 300；源本身低清时如实记录，不靠插值声称提高清晰度。不把小刻度图统一缩到固定 5.5cm。
- 图片与关联段落在内容流中相邻；用适度 keepNext 保持关联，避免整道超长题 keepNext 链形成大片空白。
- 原生表格不浮动、不嵌套，使用可随目标页面缩放的宽度。不使用文本框、VML、OLE、链接图片、绝对定位、按源页硬插的分页符和段内分节符承载正文。
- 原生上下标用 run 属性；复杂公式用 OMML 并渲染核对。不可由分数碎片顺序猜分子分母。公式图像回退要清晰、内联、只包含该表达式。
- 使用专用样式名（如 `PHC Body`）降低与目标文档 Normal/Heading 样式冲突；关键字体和字号在 run、必要段落属性中明确设置。命名独特不能保证所有应用都保留样式，仍需真实粘贴验证。
- 仅在 body 末尾保留文档级页面设置；正文分节符为零。删分节符不等于删内容，但不得不经核对删除有文字/图的段落。

## 复制语义

默认测试“保留源格式”粘贴到正常 A4 空白文档，再测试粘贴到已有正文的文档。合并格式和仅文本模式具有不同语义：仅文本会丢图片和公式格式，不承诺保留完整讲义。

用实际应用菜单/快捷键走复制粘贴，保存粘贴后的文档，回读文字、公式和图片实例，渲染全部页面检查。单纯将 XML 节点拼到另一个 docx 或用 LibreOffice 打开输出文件，都不是实际剪贴板测试。不要改写用户剪贴板中重要内容而无记录；测试完成后在可行时恢复。

测试至少包含数字/上下标/复杂公式、图及图注、跨页题、表格和多选项；若全篇全选复制是目标，必须测试全篇，不能以一题代替。记录应用、版本（可取得时）、粘贴模式、目标页面与样式、实际观察结果。未测试的应用兼容性保持未知。
